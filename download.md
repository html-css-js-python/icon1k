## Linux

Unfortunately, there is no pre-built version for Linux, but you can run the program directly from source.

First, clone the repository:
```shell
git clone https://github.com/html-css-js-python/icon1k.git
cd icon1k
```

Next, install Tkinter:
```shell
sudo apt update
sudo apt install python3-tk
```

You can now run the program:
```shell
python app.py 128 64
```
